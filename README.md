# PLAYNOVA
Your World of Games.

Free virtual-coin Flutter Android arcade app.

## Build
1. Open this folder in a Flutter-capable environment.
2. Run `flutter pub get`
3. Run `flutter analyze`
4. Run `flutter test`
5. Run `flutter build apk --release`

Package: `com.playnova.games`

The project contains 17 separate game modules and a centralized GameRegistry for future expansion.

Virtual coins are free-only. No deposits, withdrawals, betting, cash prizes, or payment processing are implemented.

Note: Android launcher binaries/Gradle wrapper JAR are normally generated by Flutter tooling. The project includes the Gradle wrapper properties and launcher resource XMLs, but a Flutter installation should regenerate platform wrapper files if needed.
